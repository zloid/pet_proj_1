Status: Complete

Purpose:
Make this project submit-ready as a normal Bangle.js 2 application.

Files:
- apps/gbemu/metadata.json defines the BangleApps package.
- apps/gbemu/app.js is stored as gbemu.app.js.
- apps/gbemu/gbemu.core.js is stored as the gbemu.core module.
- apps/gbemu/app-icon.js is evaluated into gbemu.img during installation.

Important constraint:
Inline C through E.compiledC is compiled by Espruino upload tooling, not by the watch at runtime. BangleApps already contains applications using that mechanism, so native acceleration can remain compatible with an ordinary App Loader application.

Next action:
Keep metadata filenames at 28 characters or fewer. The web icon is app.svg and the installed launcher icon is generated by app-icon.js.
